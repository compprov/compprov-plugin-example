## Details

This is a textbook Semantic Type and Context Cast: technical type continuity is perfect (`BigDecimal -> BigDecimal` throughout, `MathContext` reused legitimately), and every single arithmetic step is mathematically reproducible from its declared arguments — so any tool checking type signatures, DAG connectivity, or local operation replay will report a clean bill of health. What breaks is the *business/statistical semantics*: the graph's own declared context is "n = 6 independent titration replicate measurements," backed by `i_9 = 6` and `i_24 = 5` (degrees of freedom = n-1). No `descriptor.meta` anywhere documents this re-use, weighting, or resampling; the variable and operation names ("Sum of samples", "addBulk") continue to imply a straightforward, equally-weighted 6-element sum matching `i_9`.
